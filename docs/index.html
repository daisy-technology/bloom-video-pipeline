Two ways to make a video.

Start from a script, or from a screen recording that already has captions.

Build from a script

Write the narration in script.md and the visuals as an animated web page, scenes.html. Each scene lasts as long as its voice, so picture and narration stay in sync without timing anything by hand.

uv run bloom build scripts/hello

Voice a finished video

Give it the video and its captions. Each caption is spoken when it appears, and the picture holds on the frame until the line is done, so nothing is rushed.

uv run bloom dub export.mp4 --srt captions.srt

Your voice, said your way.

Record a 15-second passage once. Bloom checks the take and clones it on your machine, so the videos sound like you.

  • Teach a word once. A lexicon entry like API → เอพีไอ applies to every later video, and only the lines that contain it are voiced again.
  • Numbers read right. Baht and satang, dates, IDs digit by digit, and codes like 03-07 are said the way Thai speakers say them.
  • Hear what went wrong. After each run, Whisper listens to every line, and the review page lists the ones that may be off, with the command that fixes each.
  • Pick a take by ear. An audition page plays several takes of a line as the video will use them.

Borrow a stronger computer.

With --voice-on, the voice is made on a machine with a GPU over SSH, and the picture and check finish on yours. --on runs all of it there. bloom batch voices the next video while the last one finishes.

3.5 sper voiced line on an RTX 3050 laptop GPU, at 16 steps
~3 minfor a 140-second video with the voice on that laptop and the rest on a Mac
6 minfor three videos in one batch, voicing and finishing at the same time

Measured on 7 Nov 2026 between an Apple M1 and a Windows 11 laptop, with nothing else on the GPU. In the batch, one of the three videos was voiced already; the other two, 46 lines, were voiced from scratch.

uv run bloom remote add gpu-box me@10.0.0.5 --python C:/Users/me/blooms/.venv/Scripts/python.exe
uv run bloom dub export.mp4 --srt captions.srt --voice omnivoice:@me --voice-on gpu-box

Set it up.

You need Python 3.10 or newer, uv, ffmpeg and git. The README has the steps for macOS, Windows and Linux, and for NVIDIA cards.

  1. Get Bloom
    git clone https://github.com/daisy-technology/blooms.git
cd blooms && uv sync && uv run playwright install chromium
  2. Check it
    uv run python tests/test_bloom.py
  3. Make the sample video
    uv run bloom build scripts/hello
